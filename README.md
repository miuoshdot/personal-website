# 👋 Hi, I'm Miłosz Miśkiewicz

This repository contains [milosz.codes](https://www.milosz.codes) - my personal website pretending to be Apple Notes.

It started with a simple idea: a portfolio does not necessarily have to look like a portfolio. Instead of another traditional landing page, I wanted something familiar, personal, and slightly more fun to explore.

The first production version was designed, built, and polished in roughly 24 hours with Codex as my coding partner.

## What is this?

The website borrows the familiarity of a notes app and turns it into a personal corner of the internet.

You can navigate it like a long note, switch to a gallery, search through the content, change themes, and stumble upon a few macOS-inspired interactions and easter eggs along the way.

Some buttons are useful. Some are coming soon. Some should probably not be clicked.

## Under the hood

The project is made with:

- plain HTML for content and structure,
- CSS for the Apple Notes-inspired interface,
- vanilla JavaScript for navigation, search, themes, gallery view, and gestures.

I wanted to keep the stack as simple as possible, without unnecessary frameworks or dependencies.

## Apple-ish by design

The main visual inspiration is Apple Notes, including its layout, spacing, colors, typography, sidebar, toolbar, and general feel.

On Apple devices, the website uses the native system font stack, which resolves to San Francisco. On other platforms, it falls back to [Inter](https://fonts.google.com/specimen/Inter) to keep the experience as consistent as possible.
